#AulaNova_Research

This repository contains all materials related to the **AulaNova** project, including scripts, statistical analyses, example datasets, questionnaires, and a research paper.

## Repository Structure

- **llmEd**  
  Project scripts and main tool implementation.

- **llmEd_statistics**  
  Scripts for calculating statistical indices such as **mean**, **median**, **standard deviation (SD)**, and **IQR** on:
  - `time_performance`  
  - `tokens_performance`  
  - `cost_performance`

- **prompt_dataset**  
  Example input/output token files:
  - `input_tokens`  
  - `output_tokens`

- **questionnaires**  
  Questionnaires used in the study:
  - SUS (System Usability Scale)  
  - Pre-experiment questionnaire  
  - Satisfaction questionnaire  
  - UTAUT questionnaire

- **AulaNova_PLS Analysis Main**  
  Partial Least Squares (PLS) analysis for the AulaNova UTAUT2 project.

- **paper**  
  Research paper related to the AulaNova project.
